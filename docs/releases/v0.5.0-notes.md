# ADS v0.5.0 Lite — release notes (candidate)

**Status:** development candidate on `dev` / integration to `cnb/dev`. Not published until a separate release PR to `main` with owner authorization.

## Intent

Return ADS to a **lightweight agent-native standard**: pinned submodule + short root `AGENTS.md` + `STANDARD` / `SAFETY` / `QUALITY`. Optional profiles carry Strict Git, CodeGraph/RTK, and Strict Lifecycle. One published tag for all consumers; CNB remains a provider capability, not a second ADS product.

## Included

- Normative [lite adoption](../lite-adoption.md) and slim [templates/AGENTS.md](../../templates/AGENTS.md)
- Optional profiles under `profiles/` (strict Git, consumer toolchain, strict lifecycle)
- Shared CI recognition of `cursor/**` task branches and `cnb/dev` as an alternate development base when targeted
- Explicit Mode A note: GitHub sync-branch PR merge ≠ exact-SHA mirror PASS ([cnb-sync.md](../cnb-sync.md))
- Mode B remains cancelled; no extra approvers or orchestrators

## Not included / not claimed

- Mirror-system rewrite for PR-merge SHA compatibility (out of scope)
- Automatic OS sandbox for local TUI (host enforcement remains as previously documented)
- Consumer repository migrations (separate pin-update PRs after publication)

## Dual development line

| Branch | Role |
| --- | --- |
| `dev` | General Lite integration |
| `cnb/dev` | Same Lite source plus CNB specialty (workflow triggers / development-branch env); integrate via merge from `dev`, never force-overwrite |
| `main` | Published releases only |
