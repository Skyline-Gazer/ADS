# ADS v0.5.0

**Published:** [GitHub Release v0.5.0](https://github.com/Skyline-Gazer/ADS/releases/tag/v0.5.0) on `main` at `9bd8b115fa7a3bff19c0d69c22c0423c7141e63f` (2026-10-30). Lite adoption default. Immutable prior releases (`v0.4`–`v0.4.2`) are unchanged. Consumers advance the `.ads` pin through a reviewed submodule PR to tag `v0.5.0`.

## Behavior

- **Default:** [lite adoption](../lite-adoption.md) — pinned submodule + short root `AGENTS.md` + `STANDARD` / `SAFETY` / `QUALITY`. No mandatory copy of governance scripts, CodeGraph/RTK preflights, or lifecycle receipts.
- **Optional profiles:** Strict Git, consumer developer toolchain (CodeGraph + full RTK), Strict Lifecycle — enable only when named in project `AGENTS.md`.
- **Git governance:** Mandatory for the ADS repository; optional for lite consumers via profile. Cloud Agent `cursor/*` task branches are recognized. `cnb/dev` remains a valid alternate development base when targeted.
- **Provider:** GitHub Primary or CNB Primary (Mode A). Mode B remains cancelled. Do not switch provider without owner authorization.
- **Mirror:** Exact-SHA Mode A mirror policy unchanged. A GitHub sync-branch PR merge path is **not** interchangeable with exact-SHA acceptance ([cnb-sync.md](../cnb-sync.md)).

- **macOS TUI project-only read isolation: NOT_VERIFIED** where previously documented; this release does not close that gate.
