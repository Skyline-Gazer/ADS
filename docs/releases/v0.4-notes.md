# ADS v0.4 — draft release notes (NOT YET PUBLISHED)

This file is a release candidate draft only; **v0.4 has not been tagged or released**.

## Proposed additions

- Mandatory development-time CodeGraph and **full RTK** when a software project adopts ADS. A fresh environment must verify executable, actual edition, upstream stable version, initialized project, correct active host/worktree integration, usable graph, and safe output compression.
- Native auto-sync first for CodeGraph, with freshness/status checks before graph-backed decisions and explicit manual sync only when recovery is necessary. Generated graph data must never be committed.
- Stronger consumer Git lifecycle: reviewable task branches from `dev`, production branch boundary and deterministic guards, no developer tool integration on consumer production `main`, and fail-closed reports for GitHub-plan protection limitations.
- **ADS MIT License** plus a version-specific third-party license/evidence policy: CodeGraph MIT, full RTK Apache-2.0 and BUSL-1.1; distinguish internal developer use, independent product delivery, licensed engine redistribution and hosted/commercial service.
- Offline, testable license evidence validator and reproducible dev-only templates. Full RTK may not be silently downgraded to OSS.

## Not yet accepted

- The official CodeGraph npm registry is returning 404 and its official GitHub Releases collection is empty. A real full-tool bootstrap has not passed; upstream availability is required.
- GitHub Actions consumer isolation is not equivalent to verified active-host integration, and the bounded pilot is currently blocked at installation.
- This release never grants a universal all-host security guarantee or waives historical native subagent escape/permission findings.
- Consumer adoption remains a separate, scoped and reviewed change; no production application deployment is implied.

See [v0.4 release readiness](v0.4.md). Do not use these notes as an announcement until the release gates are actually fulfilled.
