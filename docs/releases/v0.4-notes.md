# ADS v0.4

ADS v0.4 strengthens development governance and tooling for projects adopting ADS.

## Included

- Mandatory Git development model: feature/fix/chore tasks originate from `dev`, land through Issue-linked PRs and CI; promotion to `main` is a separate reviewed release action.
- Development-only CodeGraph and **full RTK** integration for ADS consumers. Production `main` remains free of the tools' generated indexes, binary assets and developer host configuration; deterministic guard fixtures detect leaks.
- Prefer latest published official stable CodeGraph package; when verified npm/Releases distribution is unavailable, permit an explicitly reviewed immutable upstream **SOURCE_FALLBACK** build, with pinned SHA, MIT license evidence, exact install provenance, healthy graph/index and host MCP verification. This fallback is **not** presented as latest stable.
- Full RTK remains the official latest stable complete edition; record installed provenance, SHA256 archive hashes, Apache-2.0/BUSL-1.1 grant, and observed output compression. `rtk-oss` is not an automatic substitute.
- ADS is now published under the MIT License, without relicensing independently developed consumer code.

## Verification

- ADS repository tests and Markdown/Skill checks; remote isolated compatibility against immutable KIRARI/AiringCal source snapshots.
- Hosted CI built CodeGraph from a verified official Git SHA, indexed the two consumer codebases, ran real source-change sync and performed live CodeGraph MCP JSON-RPC tool calls.
- Official full RTK release binary and packaged license files inspected with SHA256 verification; project-local RTK commands and production boundary guards exercised.
- Private recursive pinned ADS Submodule acceptance is a distinct release gate, independently verified and recorded prior to publication.

## Known limitations

- As of the source fallback acceptance, the CodeGraph package was absent from the official npm registry and official GitHub Releases. This release does not claim an upstream latest-stable CodeGraph package exists.
- The CI matrix is bounded; it is not a universal cross-OS or cross-host native Agent certification. Each adopting project must verify its actual CodeGraph MCP binding, watcher/worktree state and RTK active-host hook operation.
- Legacy KIRARI/AiringCal snapshots contained previously tracked CodeGraph development artifacts and must not be assumed clean for promotion to production without migration and branch-boundary checks.
- Historical default subagent permission escapes and earlier experimental failures remain archived; v0.4 does not claim to remediate every host-model configuration.
- On the current private GitHub plan, server-side branch protection/Rulesets cannot be verified or enabled through the API; policy and CI do not constitute host-enforced branch protection.
- Publishing ADS does not automatically upgrade or deploy any consumer application.

For implementation and update procedures, see the [developer toolchain](https://github.com/Skyline-Gazer/ADS/blob/v0.4/docs/consumer-dev-toolchain.md), [license policy](https://github.com/Skyline-Gazer/ADS/blob/v0.4/docs/tool-licensing.md) and [v0.4 release decision](https://github.com/Skyline-Gazer/ADS/blob/v0.4/docs/releases/v0.4.md).
