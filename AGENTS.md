# Working on ADS itself

ADS is a lightweight standard, not a new execution framework. Read README.md, STANDARD.md, SAFETY.md and QUALITY.md before structural changes. Keep capabilities agent-native: SKILL.md files, concise templates and optional profiles. Do not add a CLI, runner, state machine, duplicate tracker or deployment system unless separately authorized. Preserve project-local limits. Prefer existing hosted CI for authoritative automated checks and isolated target-platform previews when needed; keep local validation lightweight and do not provision a full per-project environment by default. For edits verify Markdown links, relative paths, frontmatter and realistic task instructions. Keep changes scoped, commit on a task branch and summarize what was and was not verified.
